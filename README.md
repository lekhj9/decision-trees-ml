# Decision Trees

A structured session delivered in IIT Roorkee NPTEL Summer Internship on **Decision Trees in Machine Learning**, covering intuition, mathematical concepts, splitting criteria, model building, evaluation, and practical implementation using Python.

## 📌 About the Session

This repository contains the presentation, handwritten  e-notes and implementation resources used for a **Decision Tree Machine Learning session** conducted during my internship.

The session focused on explaining Decision Trees from fundamental concepts to practical implementation, with an emphasis on developing intuition before introducing the mathematical concepts.

## 🎯 Objectives

- Understand the intuition behind Decision Trees
- Learn how Decision Trees perform classification
- Understand tree structure and splitting
- Learn **Entropy** and **Information Gain**
- Understand **Gini Impurity**
- Study overfitting in Decision Trees
- Understand pruning and tree depth
- Implement a Decision Tree classifier using Python
- Evaluate model performance

## 📚 Topics Covered

### 1. Introduction to Decision Trees
- Decision Tree fundamentals
- Classification and Regression Trees
- Root nodes, internal nodes, branches, and leaf nodes

### 2. Intuition Behind Decision Trees

Decision Trees can be understood as a sequence of simple questions that progressively divide data into meaningful groups.

A real-world example was used during the session to explain the decision-making process intuitively.

### 3. Mathematical Concepts

The session covered:

- **Entropy**
- **Information Gain**
- **Gini Impurity**

### 4. Practical Implementation

The practical demonstration included:

- Loading the dataset
- Data preprocessing
- Train-test splitting
- Training a Decision Tree Classifier
- Making predictions
- Evaluating the model

### 5. Model Evaluation

The implementation demonstrates:

- Accuracy
- Confusion Matrix
- Classification Report

### 6. Overfitting and Pruning

The session discussed Decision Tree overfitting and methods to control tree complexity using parameters such as:

- `max_depth`
- `min_samples_split`
- `min_samples_leaf`
